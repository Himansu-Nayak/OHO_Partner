# OHO Partner App

A modern, responsive partner application for the OHO Delivery Network.

## Features

- **Dashboard:** View earnings, daily stats, and active orders.
- **Order Management:** Accept/reject incoming orders, manage active deliveries.
- **Live Navigation:** Real-time routing and navigation using Leaflet maps.
- **Profile & History:** Track past orders, earnings breakdown, and customer reviews.

## Tech Stack

- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4
- **Maps:** Leaflet & React-Leaflet
- **Language:** TypeScript

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## Design

Built with an optimized mobile-first layout. The UI features a custom mobile device frame and dynamic micro-interactions.
